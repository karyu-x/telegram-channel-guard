# Telegram Channel Guard

Простой Telegram-бот, который автоматически удаляет настоящие пересылки
из одного конкретного канала:

`@ibragimmansurov_blog`

База данных не используется.

## Railway

Нужна только одна переменная:

```env
BOT_TOKEN=токен_бота
```

Start Command:

```bash
python bot.py
```

Никакой Volume и `DB_PATH` не нужны.

## Telegram

1. Добавь бота в нужную группу.
2. Сделай его администратором.
3. Дай право удаления сообщений.
4. Напиши `/status`.
5. Перешли в группу пост из `@ibragimmansurov_blog`.

Если Telegram сохранил источник пересылки, бот автоматически удалит сообщение.

## Ограничение

Бот блокирует именно настоящие Telegram Forward-сообщения.

Если пользователь вручную скопировал текст, скачал медиа и загрузил его заново
или иным способом убрал информацию об источнике, определить исходный канал
через обычный Bot API невозможно.
