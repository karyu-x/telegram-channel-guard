# Telegram Channel Guard v4

Версия без базы данных, использующая:

- `aiogram` / Bot API — для модерирования группы;
- `Telethon` / обычный Telegram user account — для чтения реальной истории
  публичного канала `@ibragimmansurov_blog`.

## Что удаляется

1. Настоящие Forward из `@ibragimmansurov_blog`.
2. Только конкретные связанные ссылки/username:
   - `@ibragimmansurov_blog`
   - `@manager_ibragimmansurov`
   - соответствующие `t.me`, `telegram.me`, `tg://` ссылки.
3. Скрытые text_link на эти username.
4. Точные копии текста постов.
5. Почти точные копии длинных текстов.
6. Скачанные и повторно загруженные фотографии.
7. Обычные видео и видеокружки по Telegram thumbnail.

Другие `t.me` ссылки бот НЕ удаляет.

## Почему Telethon

Bot API не предназначен для чтения произвольной старой истории чужого канала.
User-account через Telethon получает настоящие сообщения канала и их Telegram
media/thumbnails.

В `bot.py`:

```python
SOURCE_HISTORY_LIMIT = 2000
```

означает, что при запуске бот постепенно сканирует до 2000 последних сообщений
канала.

Сначала быстро сканируются последние:

```python
SOURCE_QUICK_SCAN_LIMIT = 120
```

поэтому бот не ждёт завершения всей истории для запуска.

## Railway Variables

В Railway → Service → Variables добавь:

```env
BOT_TOKEN=...
API_ID=...
API_HASH=...
TELETHON_SESSION=...
```

`API_HASH` и `TELETHON_SESSION` являются секретами.

Не добавляй их в GitHub.

## Railway Start Command

```bash
python bot.py
```

Volume и DB_PATH не нужны.

## После deploy

Добавь бота администратором группы с правом удаления сообщений.

Напиши:

```text
/status
```

Нормальный результат:

```text
Telethon: подключён
Кэш текста: ...
Кэш медиа: ...
Полный скан: идёт / завершён
Обработано истории: .../2000
```

Полный скан может продолжаться в фоне.

Команда:

```text
/rescan
```

доступна администратору группы и запускает повторный полный скан.

## Проверка видеокружка

После того как `/status` показывает ненулевой `Кэш медиа`, скачай старый
video message из канала A и загрузи его в группу как новый video message.

Если thumbnail достаточно близок визуально к исходному, бот удалит его.

## Ограничение

Для видео v4 специально не скачивает все многомегабайтные ролики канала на
Railway. Она использует Telegram thumbnails. Это значительно легче для Free
Railway.

Если один и тот же ролик после сильного монтажа получает полностью другой
thumbnail, он может не совпасть. Для такого крайнего случая понадобится
полный video-frame fingerprinting с загрузкой роликов.
