# Telegram Channel Guard

Бот-модератор для Telegram-групп. Он удаляет обычные пересылки (Forward)
из каналов, которые администратор группы добавил в чёрный список.

## Возможности

- `/blockchannel` — ответить командой на пересланный пост канала.
- `/unblockchannel` — ответить на пересланный пост или указать ID канала.
- `/blockedchannels` — показать список заблокированных каналов.
- `/status` — проверить, есть ли у бота права администратора и удаления.
- Отдельный список блокировок для каждой группы.
- SQLite: настройки сохраняются после перезапуска.
- Управлять списком могут только администраторы группы.

## 1. Создание бота

1. Открой `@BotFather` в Telegram.
2. Выполни `/newbot`.
3. Получи токен.
4. Скопируй `.env.example` в `.env`.
5. Вставь токен:

```env
BOT_TOKEN=123456789:YOUR_TOKEN
```

## 2. Запуск на Windows

PowerShell:

```powershell
cd telegram_channel_guard
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python bot.py
```

Или запусти `start_windows.bat`.

## 3. Настройка группы

1. Добавь бота в группу.
2. Сделай его администратором.
3. Обязательно включи право **Delete messages / Удаление сообщений**.
4. Для проверки напиши в группе `/status`.

## 4. Блокировка канала

1. Перешли в группу любой пост из нежелательного канала обычной кнопкой Forward.
2. Ответь на пересланный пост:

```text
/blockchannel
```

После этого следующие настоящие пересылки из этого канала будут удаляться
автоматически.

## 5. Разблокировка

Ответь на пересланный пост:

```text
/unblockchannel
```

или используй ID из `/blockedchannels`:

```text
/unblockchannel -1001234567890
```

## Ограничение Telegram

Бот распознаёт источник благодаря `forward_origin`, который Telegram передаёт
для настоящей пересылки. Если человек вручную скопировал текст, скачал файл и
загрузил его заново или использовал функцию копирования без сохранения
источника, у сообщения нет `forward_origin`, поэтому определить исходный канал
по одному Telegram Bot API уже нельзя.

## Privacy Mode

Отдельно отключать Privacy Mode не нужно, если бот добавлен в группу
администратором: Telegram передаёт ботам-администраторам все сообщения группы.

Главное — выдать боту право **Delete messages / Удаление сообщений**.

## Остановка

В терминале нажми `Ctrl+C`.
